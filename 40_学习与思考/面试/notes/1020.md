1.bf16 & fp16 & fp32
```
1.bf16表示的范围更大，fp16表示的精度更高
2.bf16优势是数值稳定性：
	训练过程中梯度会横跨几个量级，如果使用fp16做混合精度训练，需要做loss scaling；使用bf16无需loss scaling
```

2.decoder-only的原因
```
1.训练目标和生成任务高度一致；训练数据可以直接来自海量文本和代码，文本自身就提供了预测标签；到了对话、写代码和推理阶段，模型仍然是在已有上下文上继续生成。这让预训练获得的能力能自然迁移到下游生成任务。
2.任务接口统一，非常适合通过上下文完成任务。指令、示例、用户问题和工具返回结果，都可以放进同一条序列，模型接着生成回答或工具调用。
3.结构统一，便于规模化训练和部署。Decoder-only 使用一套重复堆叠的 Transformer 模块，省去了独立的编码器和编码器—解码器交叉注意力，训练并行、算子优化和推理服务更容易围绕统一结构积累。
```

3.YaRN
```
1.**位置插值后按频段调整旋转频率**，高频保持不变，低频做插值，中频平滑过渡。公式:w` = gamma * w + (1 - gamma)(w/s)，高频gamma = 1；
2.调整注意力温度，乘到sqrt(d_k)上。经验值sqrt(1/t) = 0.1ln(s) + s。
```

4.Post-LN & Pre-LN
```
1.post-ln指Attention + FFN，和残差链接后再做LN；相当于正则项，缺点是深层会梯度消失，训练不稳定；
2.pre-ln指Attention + FNN，然后做LN，再做残差链接；训练稳定，缺点是效果不佳。
```
