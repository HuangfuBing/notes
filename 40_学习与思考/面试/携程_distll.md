4.**影响描述的好坏评价**
```
我把影像描述的质量分为事实准确性、关键信息覆盖和表达专业性。医生审核负责确认图像与描述的对应关系，修订记录反映实际使用反馈，编辑距离量化医生的修改负担。

这些信号各有分工：医学内容由专业审核把关，使用成本由修改量体现，疾病标签再提供结构化的一致性检查。

在数据构造阶段，我们结合医生整理的影像特征语料库生成报告，再交由医生做质量控制，为模型提供专业的表达起点。
```
*编辑距离的奖励设计，可以说冷启动后起点较好，医生一次采纳率和pass@k正相关，模型的rollout中存在合格报告，所以可以使用编辑距离。*
```
后续改进：
1.把病灶的位置、形态、范围变成监督目标
例如利用Qwen3（或其他支持bounding box的LLM），构造包含病灶位置 + 影像学描述的目标报告，再对bounding box和文本描述分别计算损失。
2.检测结果注入prompt中，考虑使用弱监督/无监督方法训练目标检测模型，抑制人工标注带来的噪声。
```

5.医生提出过的反馈
```
医生给过一个很具体的反馈：报告需要更贴合 SLO 的专业描述习惯。针对这个需求，我们整理了每类疾病的典型影像特征，把医生知识加入报告构造，再由医生进行质量检查。

后续医生认可了诊断表现，同时提出进一步细化影像描述的建议。这为下一步工作指明了方向：增加图像与局部征象的对应监督，使描述更具体、更贴近医生的判读过程。
```

7.旅行规划Agent
```
和医疗项目的不同之处：多步交互、工具环境和长轨迹评价
我选择旅行规划，是因为它同时包含时间、地点、预算和交通等约束，而且前一步查询结果会影响后续决策。例如查到交通时间过长，就需要调整景点安排，很适合检验模型利用环境反馈进行多步决策的能力。
```

8.旅行规划Agent，想探索什么问题，支持了哪些结论
```
1.高质量轨迹蒸馏可以建立小模型的基础工具交互能力
2.在线强化学习能在 SFT 基础上进一步提升任务表现
3.多工具任务存在多条可行路径，奖励设计需要约束交互行为，并保留路径探索空间
```

9.为什么格式奖励权重先高后低
```
我采用分阶段奖励权重，让训练重点随目标能力逐步推进。早期提高格式奖励，帮助模型形成稳定的工具交互协议；后期增加任务质量奖励，引导模型利用工具反馈完成用户约束。
```
